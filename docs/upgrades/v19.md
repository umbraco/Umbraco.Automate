# Upgrade to Umbraco 19

From `18.1.0` to `19.0.0-beta1` (tag `release-19.0.0-beta1`).
Branch `v19/dev`, cut from `v18/dev`.

**Targets CMS release:** `release-19.0.0-beta1`. This is a pre-release, so all three products
ship as pre-releases too: `19.0.0-beta`, following the `18.0.0-beta` naming used for v18.

## Inventory

Sources were checked against the CMS clone at `release-18.1.0` and `release-19.0.0-beta1`, the
19.0.0-beta1 release notes, and
[Version specific upgrades, Umbraco 19](https://docs.umbraco.com/umbraco-cms/19.latest/get-started/upgrading-and-migrating/version-specific).
The docs page says 19 upgrades from 16.4 or later, so the hop from 18.1.0 is allowed.

## Decisions

- 02-11-2026: No third-party majors in this upgrade (JsonSchema.Net.Generation 7 and Cronos 0.13

## Breaking changes for consumers

- .NET 11 and CMS 19 are required.
- Removed: `NotifyEditorAction`'s obsolete constructor; `AutomateOptions` obsolete member at
  line 24; `GovernanceOptions` and `Umbraco:Automate:Governance`; `ScriptingOptions` and
  `ScriptExecutorOptions` obsolete members.
- `IAutomationRunService`, `IAutomationActionAuthorizer` and `IOAuthCredentialsService` lose
  their default implementations: custom implementations must implement those members.
- Find Content / Find Media: any setting that can't be kept on Umbraco Search (to be filled in
  by task 2).
- Dropdown settings render with the single-select editor (same stored value shape).

## Follow-ups

- Third-party majors not taken in this upgrade: JsonSchema.Net.Generation 5.1.1 → 7.4.1
  (breaking for consumers, so only in a future major) and Cronos 0.9.0 → 0.13.0 (internal, can
  go in any minor).
- Add Clean back to the v19 demo scripts once a CMS 19 release of it ships.
- `collectionView.meta.pathName` is deprecated (removal in Umbraco 20) but still required at 19.
  Remove it in the v20 upgrade.
- The legacy tracked `demo/` folder still sets `AllowEditInvariantFromNonDefault`
  (`demo/Umbraco.Automate.DemoSite/appsettings.json:22`), which 19 removes. Consider deleting `demo/`.
- `templates/umbraco-automate-actions` pins `Umbraco.Automate.Core` and `.Testing` at `0.1.*`,
  stale since before this upgrade.
- The Core client imports bare `diff` (`version-diff-view.element.ts:5`) without declaring it;
  it's bundled through the backoffice peer.
- Backport: none expected. This is a new line; v17 and v18 stay as they are.
